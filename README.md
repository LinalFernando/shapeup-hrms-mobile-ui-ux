# ShapeUP – HRMS Mobile App UI/UX

A modern **Human Resource Management System (HRMS) mobile application UI/UX design** created using **Figma**.

The project focuses on creating a clean, simple, and user-friendly mobile experience for HR and employee-related activities.

## 🎨 Design Tool

- Figma

## 📱 Project Overview

ShapeUP is a mobile HRMS application concept designed to provide users with an easy way to access and manage HR-related information and activities.

The design focuses on:

- Clean and modern mobile interfaces
- Simple and intuitive navigation
- User-friendly interaction
- Consistent visual design
- Clear information hierarchy
- Reusable UI components

## ✨ Key Design Work

- Designed high-fidelity mobile application screens
- Created user flows and navigation structures
- Developed wireframes and UI concepts
- Created interactive prototypes in Figma
- Designed reusable UI components
- Applied consistent typography, spacing, colors, and visual hierarchy
- Focused on usability and mobile user experience
